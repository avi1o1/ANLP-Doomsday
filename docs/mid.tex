\begin{abstract}
Learned sparse retrieval, block-sparse attention and mixture-of-experts routing each
select items by an inner product over learned non-negative features followed by a hard
top-$k$. Only retrieval corrects this score, through the inverse document frequency
(IDF), term saturation and length normalisation of BM25. We ask when the correction
helps a learned representation and whether the answer can be predicted without
relevance labels. We score fourteen sparse representations derived from one frozen
encoder under all eight combinations of the three components on thirteen collections,
in 182 primary and 1{,}226 sensitivity rows. The correction raises nDCG@10 in $90\%$ of
primary rows. An exact Shapley attribution assigns $61\%$ of the gain to saturation,
which reads no collection statistics. The pre-registered predictor, built on frequency
diagnostics, does no better than always predicting a gain. Statistics of the index
predict the saturation component. The value of IDF and length normalisation depends on
relevance. In exploratory analysis only a pseudo-relevance proxy predicts it on
held-out corpora ($R^2$ of $0.52$ to $0.66$). A decision rule built on that proxy raises
mean nDCG@10 from $0.143$ to $0.148$, against $0.151$ for an oracle. Adapters for
attention and routing are implemented and will receive the frozen predictors next.
\end{abstract}

\section{Introduction}
\label{sec:intro}

A learned sparse retriever scores a query $q$ against a document $d$ as
$\langle u_q, u_d\rangle$ over a vocabulary of non-negative features and returns the
top $k$ \citep{formal2021splade,nguyen2023unified}. A block-sparse attention kernel
scores KV page $i$ for query $q_t$ as $\langle q_t, c_i\rangle$ over page summaries and
attends to the top-$k$ pages \citep{tang2024quest}. A mixture-of-experts router gates on
$\langle h_t, w_e\rangle$ and sends the token to its top-$k$ experts
\citep{shazeer2017moe,fedus2022switch}. The three settings share one computation
(Figure~\ref{fig:overview}).

Lexical retrieval learnt long ago to correct this score. BM25 down-weights features that
occur across the collection, saturates repeated evidence and normalises for document
length \citep{sparckjones1972idf,robertson2009bm25}. Whether the correction helps
learned features is unsettled. On one benchmark suite, BM25 over sparse-autoencoder
features beats their inner product by $0.20$ nDCG@10 while BM25 over SPLADE-v3 loses by
$0.11$ \citep{clavie2026latent}. The published explanation is qualitative. BM25 helps
while a vocabulary keeps a Zipfian frequency curve \citep{clavie2026latent,han2026bm25v}.

We make the question testable. From one frozen encoder we build fourteen sparse
representations and score each under all eight combinations of IDF, saturation and
length normalisation on thirteen collections, including three Indic ones. The retrieval
setting is complete. The correction helps in $90\%$ of primary rows. Saturation, the
one component that reads no collection statistics, carries $61\%$ of the gain. A
predictor fixed in advance from frequency diagnostics fails. We trace the failure to the
components themselves. The effect of saturation is a property of the stored values,
while the value of IDF and length normalisation depends on relevance. Section~\ref{sec:problem}
states the problem formally and Section~\ref{sec:progress} reports the results.

\section{Problem Statement}
\label{sec:problem}

\paragraph{The correction.} For query and document vectors $x_q, x_d$ with
non-negative coordinates we score
\begin{equation}
S(q,d) = \sum_{j} x_{qj}\, w_j\, T(x_{dj}, \ell_d).
\label{eq:scorer}
\end{equation}
The weight $w_j$ is one or the smoothed inverse document frequency
$\idf_j = \ln(1 + (N - df_j + 0.5)/(df_j + 0.5))$, where $df_j$ of the $N$ documents have
feature $j$. The length factor $\ell_d$ is one or $1 - b + b L_d/\overline{L}$ with
$L_d = \sum_j x_{dj}$. The transform $T(f,\ell)$ is $f/\ell$ or the saturated
$(k_1+1)f/(f + k_1\ell)$. Each component is a switch, so a configuration is a bit string
$c \in \{0,1\}^3$ in the order IDF, saturation, length. Configuration \texttt{000} is
the plain inner product and \texttt{111} is BM25 \citep{robertson2009bm25}. IDF and
length normalisation read collection statistics. Saturation reads only the document.

\paragraph{The unit of observation.} Collection frequency belongs to a corpus, so one
row of the analysis pairs a representation with a collection at a support budget (the
query and document feature caps), BM25 parameters $(k_1, b)$ and a basis seed. Each row
carries eight nDCG@10 values $Q_c$, one per configuration.

\paragraph{What is predicted.} The pre-registered target is the margin
$m = (Q_{111} - Q_{000})/\operatorname{sd}(Q_{000}, \ldots, Q_{111})$, a standardised
effect on the same scale in every setting. Section~\ref{sec:progress} shows that $m$ is
poorly shaped for prediction. We therefore add targets defined on the same eight values.
The Shapley value $\phi_s$ of switch $s$ is its marginal effect averaged over every order
in which the switches can be turned on \citep{shapley1953value}. Writing $Q_A$ for the
configuration with the switches in $A$ on,
\begin{equation}
\phi_s = \sum_{A \not\ni s}
\tfrac{|A|!\,(2-|A|)!}{6}\bigl(Q_{A\cup\{s\}} - Q_{A}\bigr).
\label{eq:shapley}
\end{equation}
The three values sum exactly to $Q_{111} - Q_{000}$. The collection gain
$G = Q_{111} - Q_{010}$ is the value of IDF and length normalisation once saturation is
applied. Its sign is the decision the project is about, whether to use collection
statistics for a given representation and collection. A predictor maps label-free
quantities to $m$, $\phi_s$ or $G$. It is scored by sign accuracy against the majority
sign, by held-out $R^2$ and Spearman correlation. For $G$ it is also scored by the nDCG@10 obtained when
collection statistics are used only where the prediction is positive.

\paragraph{Transfer.} Eq.~\eqref{eq:scorer} applies to any selection with a non-negative
score and a selection count. For KV page $i$ at decode step $t$, the feature value is the
softplus of the Quest criticality $r_{t,i}$. Its frequency $\sfreq_i$ is the fraction of
calibration queries for which the page enters the top-$k$ among the pages that exist at
that point. Its length is the norm of the page's concatenated key minima and maxima. For
expert $e$ at a token, the value is the router probability $p_e$, the frequency is the
share of calibration tokens routed to $e$ and the length is the norm of the router logits.
The selected experts are combined with their original gate weights, so the correction
changes only which experts run. In attention a row is a model, RULER task, context length
and token budget, scored by RULER accuracy. In routing a row is a model and task, scored
by negative token log-likelihood on WikiText and zero-shot MMLU accuracy. A predictor
fitted in retrieval is applied there without refitting. The registered criterion is a
sign accuracy of at least $70\%$ and a mean absolute error of at most $1.5$ times the
corpus-held-out RMSE in retrieval. Always predicting a gain already reaches $90\%$ sign
accuracy in retrieval, so before any transfer run we add a third condition. The
predictor must also beat the majority sign.

\section{Motivation and Research Gap}
\label{sec:motivation}

The selectors above use the raw match score. They take no account of how often a
feature is selected across the collection, how evidence accumulates within an item or how
large the item is. Lexical retrieval corrects for all three with parts that arrived
separately. These are inverse document frequency \citep{sparckjones1972idf},
term-frequency saturation \citep{robertson1994poisson} and pivoted length normalisation
\citep{singhal1996pivoted}, combined in BM25 \citep{robertson2009bm25}. Inside the
transformer only fragments have been reinvented. Loss-free balancing adds a per-expert
bias driven by recent load \citep{wang2024lossfree}, an additive frequency discount with
no saturation or length term. Streaming inference keeps the first keys of the cache as an
exception \citep{xiao2024streamingllm}.

Three papers have scored the same learned features with and without the correction, all
in retrieval. BM25 wins on sparse-autoencoder features of a dense retriever
\citep{clavie2026latent} and on SAE concept units \citep{park2025clsr}. It comes out level
on visual words \citep{han2026bm25v}. Two of these papers give the Zipfian explanation.
None of the three varies the vocabulary systematically or attributes the gain to the three
components. The explanation has not been turned into a quantity that can be computed
before the experiment, nor tested where the same computation runs inside a model.

\section{Contributions}
\label{sec:contributions}

\begin{enumerate}
\item \textbf{A controlled grid.} Fourteen sparse representations from one frozen encoder
are scored under all eight configurations on thirteen collections, with sensitivity
families over support budget, $k_1$, $b$, basis seed and collection-statistic controls.
The grid has 182 primary and 1{,}226 sensitivity rows. A second run on different hardware
reproduces the primary rows it shares.
\item \textbf{An attribution of the gain.} Exact Shapley values show that saturation, a
per-document transform, carries $61\%$ of the gain. IDF alone carries about a tenth. Its share
falls as the support budget grows.
\item \textbf{A negative result with its cause.} The pre-registered predictor does no
better than the majority sign. Frequency diagnostics describe the index, while whether
IDF and length help depends on relevance.
\item \textbf{An exploratory label-free predictor.} Scoring each configuration against a
reference retriever's ranking predicts the three components and the collection gain on
held-out basis families and corpora.
\item \textbf{Transfer adapters.} KV-page selection and expert routing implement
Eq.~\eqref{eq:scorer} and pass native-parity tests. They have not yet been run at scale.
\end{enumerate}

\section{Related Work}
\label{sec:related}

\paragraph{Term weighting.} IDF was proposed as a statistical account of term specificity
\citep{sparckjones1972idf}. Saturation came from approximating the two-Poisson model of
within-document frequency \citep{robertson1994poisson}. Length normalisation was pivoted
so that long documents are neither favoured nor penalised \citep{singhal1996pivoted}.
BM25 combines the three \citep{robertson2009bm25}. Each part was motivated by word
statistics, so it is open whether it helps features that are not words.

\paragraph{Retrieval scorers.} Dense retrievers score by the inner product of embeddings
\citep{karpukhin2020dpr}. Our encoder is multilingual E5 \citep{wang2024me5}. Learned
sparse retrieval keeps the inverted index and learns term weights, through contextual
exact match \citep{gao2021coil} or expansion over the subword vocabulary in SPLADE
\citep{formal2021splade,formal2021spladev2,lassance2024spladev3}. Two frameworks place
these methods side by side \citep{lin2021conceptual,nguyen2023unified}. Learned weights
also change the cost of query processing \citep{mackenzie2021wacky}, which is why we
report posting visits and index size. All of these methods score by inner product.

\paragraph{Learned concept vocabularies.} Sparse autoencoders decompose dense activations
into many non-negative features \citep{cunningham2024sae}. Top-$K$ SAEs fix the number
active per input \citep{gao2025topksae}. In retrieval, CL-SR indexes SAE-decomposed
embeddings as concept units weighted by IDF. Dropping that weighting costs 11 to 18
percent of its nDCG@10 on TREC-DL \citep{park2025clsr}, the one published ablation of the
correction. SPLARE trains an SAE-based sparse retriever \citep{formal2026splare}.
SAE-SPLADE replaces the language-model head of SPLADE with an SAE \citep{zong2026tokens}.
Both score by inner product. Quantised codes are the other route to a discrete
vocabulary, through product quantisation \citep{jegou2011pq}, residual quantisation
\citep{chen2010rq} and their GPU implementations \citep{johnson2021faiss}.

\paragraph{BM25 on learned features.} \citet{clavie2026latent} show that SAE features of a
frozen dense retriever have roughly Zipfian collection statistics and can be scored by
BM25 directly. In their Appendix~C, BM25 reaches $0.582$ nDCG@10 against $0.381$ for the
inner product on SAE latent terms. On SPLADE-v3 it reaches $0.455$ against $0.568$. The
scorers swap places when the vocabulary changes. \citet{han2026bm25v} find the two within
about two points of R@1 on image retrieval. They attribute the parity to top-$k$ filtering
already suppressing what IDF would down-weight. Raising their per-patch budget from $16$
to $128$ makes document frequencies converge and R@1 fall from $0.508$ to $0.038$.

\paragraph{Predicting effectiveness without labels.} Query performance prediction
estimates retrieval quality from the query and the ranking alone
\citep{carmel2010difficulty}. It uses the divergence of the retrieved language model from
the collection \citep{cronen2002clarity} or the spread of the top retrieval scores
\citep{shtok2012nqc}. Retrieval systems can also be ranked without judgements by
comparing each with pseudo-relevant documents drawn from pooled output
\citep{soboroff2001ranking}. Our label-free predictor uses both ideas to predict a
difference between scorers, a target neither line of work addresses.

\paragraph{Attributing an effect to components.} The Shapley value assigns a joint outcome
to players by averaging marginal contributions over orderings \citep{shapley1953value}.
SHAP applies it to model predictions \citep{lundberg2017shap}. Over a complete $2^3$
factorial it is exact and needs no sampling.

\paragraph{Selection inside the transformer.} Quest scores KV pages by an inner product
against page min-max key summaries \citep{tang2024quest}. H2O keeps recent and
heavy-hitter tokens \citep{zhang2023h2o}. SnapKV keeps the positions an observation window
attends to \citep{li2024snapkv}. StreamingLLM keeps the first keys as attention sinks
\citep{xiao2024streamingllm}. Expected Attention prunes pairs that future queries are
predicted to ignore \citep{devoto2025expectedattention}. Massive activations single out a
few positions by magnitude \citep{sun2024massive}. None of these uses the rate at which an
entry is selected across queries. RULER measures long-context quality
\citep{hsieh2024ruler}.

\paragraph{Expert routing.} Sparse mixture-of-experts layers route each token to its top-$k$
experts \citep{shazeer2017moe,lepikhin2021gshard,fedus2022switch}. Balance comes from an
auxiliary loss \citep{zoph2022stmoe} or from a load-driven bias \citep{wang2024lossfree}.
DeepSeekMoE splits experts more finely and adds shared experts \citep{dai2024deepseekmoe}.
\citet{su2026superexperts} find a handful of experts, identified by activation magnitude,
whose removal degrades the model badly. We use OLMoE \citep{muennighoff2025olmoe}, which
activates 8 of 64 experts per layer. To our knowledge no work treats retrieval scoring,
KV selection and routing as one scoring problem.

\paragraph{Viability.} The correction costs one pass over the index. Sparse codes are cheap to build from one encoder. Label-free proxies
for quality already work for single systems. The question therefore needs no new model to
answer.

\section{Method}
\label{sec:method}

\paragraph{Representations.} All representations come from \texttt{multilingual-e5-base}
\citep{wang2024me5} at a pinned revision. Seven bases are fitted on the same $200{,}000$
MS~MARCO passages \citep{bajaj2016msmarco} and nowhere else. They are split-rectified
identity, Gaussian projection (768), PCA (384), soft $k$-means over $4{,}096$ centroids,
product and residual quantisation ($8 \times 256$) and a Top-$K$ SAE with $8{,}192$
features of which at most 32 are active. Pooled granularity applies each basis to the
mean of the content token states. Token granularity applies it to each state before
summing. This gives fourteen representations. A secondary SAE shares one dictionary
across both granularities to separate aggregation from fitting. SPLADE has its own
backbone, so it is an external comparison outside the grid.

\paragraph{Corpus statistics.} Supports are capped before any statistic is computed, at
32 query and 128 document features in the primary budget. Document frequency, lengths and
IDF come from the capped vectors of each target corpus. Retrieval is exact over the whole
corpus. The primary grid uses $k_1 = 1.2$, $b = 0.75$ and seed zero. For a fixed linear
map $C$ and diagonal weights $D$, weighted scoring is bilinear, $(Cq)^\top D (Cd) =
q^\top C^\top D C d$. It preserves every ranking of the inner product when
$C^\top D C = \alpha I$ with $\alpha > 0$. Split rectification, truncation, saturation and
length normalisation are not linear, so no representation here meets that condition. The
code checks the identity and a counterexample numerically.

\paragraph{Collections.} The thirteen collections come from eleven corpora. MS~MARCO dev,
TREC-DL 2019 and TREC-DL 2020 share one set of documents. The others are six BEIR sets
\citep{thakur2021beir}, LIMIT \citep{weller2025limit} and the Hindi, Bengali and Telugu
portions of MIRACL \citep{zhang2023miracl}, each evaluated within its language. LIMIT is
built so that the top-$k$ sets its queries need exceed what a low-dimensional embedding can
represent.

\paragraph{Runs.} The primary family (Table~\ref{tab:families}) ran on a four-GPU cluster
node for all thirteen collections. A single-GPU workstation reran it for the ten
collections outside MS~MARCO with the cluster run's fitted bases and pinned data. The
workstation also ran every sensitivity family.

\paragraph{Significance.} A paired bootstrap over queries recomputes numerator and
denominator. Holm correction \citep{holm1979} runs within each pre-declared family, the
all-on against all-off comparison and the three component main effects. The cluster run
drew $2{,}000$ samples, which puts the smallest attainable Holm $p$-value over 182
comparisons at $0.091$. We therefore report significance from the workstation run, which
drew $10{,}000$.

\paragraph{Diagnostics.} No feature describing a row reads relevance labels. The six
pre-registered frequency diagnostics are the active fraction, the Zipf slope of the
feature-frequency curve, the Gini coefficient of activation mass, frequency and
activation mass in the most frequent $1\%$ of features and IDF variance. The primary ridge
model uses the slope, IDF variance and frequent activation share. Index statistics
describe the stored values. The main one is $\mathrm{cv}_x$, the coefficient of variation
of the stored document values. Ranking features come from the stored top-100 list $R_c(q)$
of every configuration $c$ and query $q$. They include how much each switch changes the
top 10 and the shape of the top-100 scores \citep{shtok2012nqc}. The pseudo-quality
$\tilde{Q}_c$ is the mean nDCG@10 of $R_c(q)$ when the top 10 of a reference retriever on
the same query is taken as relevant. The references are text BM25, the dense encoder and
the two fused by reciprocal rank. Replacing $Q_c$ by $\tilde{Q}_c$ in
Eq.~\eqref{eq:shapley} and in $G$ gives pseudo-label estimates $\tilde{\phi}_s$ and
$\tilde{G}$ with no fitted parameter.

\paragraph{Validation.} Predictors are ridge regressions with the scaler and penalty chosen
inside training folds. Folds hold out a whole basis family (linear, clustered, quantised,
learned) or a whole corpus, reported separately. A fit on primary rows is also scored on
the rows at other $k_1$ and $b$, which share collections with it.

\paragraph{Transfer adapters.} The attention adapter implements Quest-style criticality
over sixteen-token pages with dense prefill and sparse decode. It counts how often each
page enters the top-$k$ over causal prefill positions and applies Eq.~\eqref{eq:scorer}
with pages for documents. The routing adapter applies the correction to OLMoE router
probabilities for selection and combines with the original gate weights. In both, the
all-off configuration calls the native code path. Six tests confirm exact native parity,
causal calibration, budget charging including sink pages and the gate mixture.

\section{Progress}
\label{sec:progress}

\subsection{Reproduction}

The workstation run reused the cluster run's fitted bases and pinned data, so it
reproduces the pipeline on second hardware. It is not an independent replication. Over
the 140 primary rows the runs share, the median absolute difference in all-on nDCG@10 is
$0.0007$ (maximum $0.0077$). The margin sign agrees in 136 of the 137 rows where it is
defined. The differences come from fp16 rounding on different GPUs. Text BM25 agrees to
seven decimals. Basis seeds move all-on nDCG@10 by a median standard deviation of $0.006$
over 50 representation-collection groups.

The plain inner product of the capped sparse codes nearly fails (Table~\ref{tab:quality}).
Its mean nDCG@10 is below $0.14$ on every collection. Full correction raises the mean by a
factor of $1.8$ to $14$. Token granularity is far stronger than pooled (mean all-on $0.219$

reaches $0.60$ on TREC-DL 2019, against $0.70$ for the dense encoder it comes from. On the
ten workstation collections the pooled SAE reaches $0.095$ with its own dictionary and
$0.291$ with the token-trained one, against $0.339$ at token level. Most of the pooled
deficit therefore comes from fitting the dictionary on pooled vectors. LIMIT behaves as
its construction predicts. BM25 on words reaches $0.94$, while the dense encoder and every
representation built from it stay near zero.

\subsection{Whether the correction helps}

The margin is positive in $90\%$ of the 179 primary rows where it is defined. Over the 140
workstation rows, Holm-corrected all-on against all-off comparisons are significant in 99.
The main effects of saturation, length and IDF are significant in 93, 79 and 56 rows, with
mean effects of $+0.065$, $+0.032$ and $+0.013$ nDCG@10. Full correction is the best of the
eight configurations in only 43 of the 182 primary rows. The most frequent winner, in 51
rows, is saturation with length normalisation and no IDF. The all-off configuration scores
below $0.01$ nDCG@10 in $42\%$ of workstation rows. The margin falls between $1.5$ and
$3.5$ in $83\%$ of them. It mostly records that the uncorrected scorer is broken, which
leaves little variation to predict.

\subsection{The pre-registered predictor}

The primary ridge model predicts the margin with held-out $R^2$ of $0.04$ across basis
families and $0.02$ across corpora in the cluster run. In the workstation run, with the
rows that respond to fewer than two switches excluded, the values are $-0.11$ and $0.14$.
Its sign accuracy equals the majority-sign baseline in every case ($0.899$ and $0.924$).
The six-diagnostic model reaches $R^2 = 0.30$ across corpora in the workstation run but
$-0.54$ across basis families. Its sign accuracy is never more than $0.03$ above the
majority sign. By the pre-registered criterion the frequency diagnostics carry no usable
information about the margin.

\paragraph{Mechanism.} With length normalisation off, saturation maps a stored value $f$ to
$g(f) = (k_1+1)f/(f+k_1)$. The ratio $g(f)/f$ falls as $f$ grows, so saturation shrinks
large values relative to small ones. If every stored value were equal, $g$ would rescale
all scores alike and change no ranking. The change grows with how unequal the values are,
which $\mathrm{cv}_x$ measures. A smaller $k_1$ bends $g$ more. How much saturation changes
the ranking is thus a property of the index. Outside the two equal-valued codes the change
helps in $91\%$ of cluster primary rows. Length normalisation and IDF also change the
ranking by an amount the index fixes. Whether the change helps depends on whether heavy
documents are over-rewarded relative to their relevance and on whether rare features
separate relevant documents from the rest. Both depend on relevance, which no statistic of
the index measures.

\paragraph{Prediction.} Index statistics predict saturation but fail for IDF and the
collection gain (Table~\ref{tab:predictor}). The frequency diagnostics predict none of the
targets. Pseudo-labels supply relevance information the index lacks and predict every
target. The Shapley values and $G$ are fixed linear combinations of the eight $Q_c$, so a
pseudo-quality that orders the configurations like the true one yields correlated
targets. The median within-row Spearman correlation between pseudo and true nDCG@10, over
the eight configurations of 1{,}112 rows, is $0.98$. With no fitting, the pseudo-label
estimates rank the true values with Spearman $0.91$ for saturation, $0.82$ for length,
$0.83$ for IDF and $0.66$ for $G$ on the primary rows.

\paragraph{Decision.} A rule with no fitted parameter uses collection statistics only where
$\tilde{G}$ is positive. On the primary rows it raises mean nDCG@10 from $0.1429$ (always
using them) to $0.1478$, against $0.1279$ for never using them and $0.1510$ for an oracle.
The gain of $0.0049$ is $61\%$ of the $0.0081$ available, with a collection-resampled $95\%$
interval of $0.0003$ to $0.0101$. The rule recovers $67\%$ at other budgets and $65\%$ at
other parameters. At other seeds it recovers $22\%$ and the interval reaches zero. The
gains are small in absolute terms, because always using collection statistics is already
close to the oracle on most rows. The rule itself was chosen during the exploration.

\paragraph{Choice of reference.} The main reference is text BM25. The correction under
study is BM25 applied to other features. Agreement with BM25 may therefore reward
configurations for behaving like BM25, whatever their relevance. Lexical systems also
contributed to the judgement pools of several collections. The dense reference has the
opposite weakness. The sparse codes come from the same encoder, so agreement with it partly
measures how much of the embedding a configuration keeps. The prediction of $G$ holds with
the dense reference ($R^2$ of $0.51$ and $0.66$ in Table~\ref{tab:predictor}). With that
reference the rule recovers $45$ to $75\%$ of the headroom across the four groups of rows.
Neither reference is free of bias, so the pseudo-label result stays exploratory until it
is tested on data fixed in advance.

\section{Limitations}
\label{sec:limitations}

All representations come from one encoder, so basis and encoder effects are not
separable. E5 was trained with MIRACL data, so the Indic results do not concern unseen
languages. The sparse codes are far below the dense encoder they come from, so the
attribution may not hold for strong learned sparse retrievers such as SPLADE. The label-free predictor needs queries and a second
retriever run. Its evidence is exploratory until the second pre-registered round. Routing
is inference-time only, so nothing is claimed about training dynamics.
